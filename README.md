# Lorcana Cards · ОРИС

Учебный каталог коллекционных карт. C#/.NET 8, PostgreSQL, HTML/CSS и обычный JavaScript. Исходные данные и изображения карт — Disney Lorcana / Ravensburger.

## Запуск в Docker

Запустите Docker с Compose и выполните в корне проекта:

~~~sh
docker compose up --build -d
~~~

Откройте [каталог](http://127.0.0.1:8888/). Для [входа в админку](http://127.0.0.1:8888/auth/login) используйте логин `admin` и пароль `lorcana-demo-admin`.

При первом запуске Compose заполняет PostgreSQL из папки `sql/`, а приложение создаёт администратора. Готовность можно проверить на [странице /health](http://127.0.0.1:8888/health). Для остановки выполните `docker compose down`. Данные сохранятся в томе.

Файл `.env` необязателен. Для другого порта или собственных паролей скопируйте `.env.example` в `.env` и задайте нужные значения. Пароли задаются при инициализации чистой БД. Для уже созданной БД используйте прежние значения.

## Запуск из Rider

Откройте Lorcana.sln. Создайте отдельную PostgreSQL БД и последовательно выполните оба файла из sql. Укажите переменную LORCANA_DB со строкой подключения Npgsql. Для первого входа задайте LORCANA_ADMIN_LOGIN и LORCANA_ADMIN_PASSWORD в окружении запуска. Запустите проект Lorcana через Rider или:

~~~powershell
dotnet run --project Lorcana
~~~

Адрес сервера берётся из Lorcana/settings.json. Команда stop или Ctrl+C останавливает сервер.

## Структура

~~~text
lorcana/
├── Lorcana.sln
├── Framework/                   # собственный HTTP-фреймворк: Core, Server, Settings
├── MiniTemplateEngine/          # движок HTML-шаблонов
├── MiniTemplateEngineUnitTest/  # тесты движка шаблонов
├── MyORMLibrary/                # CRUD и сопоставление моделей с таблицами
├── MyORMLibraryUnitTest/        # тест CRUD с настоящей PostgreSQL
├── Lorcana/                     # веб-приложение
│   ├── DAO/                     # доступ к данным каталога
│   ├── Endpoints/               # страницы и HTTP API
│   ├── Models/DTOs/             # DTO каталога
│   ├── Pages/                   # HTML-шаблоны по страницам
│   ├── Services/                # логика аутентификации
│   └── public/assets/           # CSS, JavaScript и изображения
├── Lorcana.Tests/               # тесты HTTP-фреймворка и приложения
├── sql/                         # схема и начальные данные PostgreSQL
├── tools/                       # скрипты тестирования и экспорта
├── Dockerfile
└── compose.yaml
~~~

Главная и карточка рендерятся на сервере и работают без JavaScript. Поиск и фильтры отправляются обычной GET-формой, ссылки на страницы сохраняют выбранные параметры. Вход, админка и обратная связь используют нативный JavaScript и fetch для отправки форм. В админке есть удаление, форматирование описаний и счётчик символов. Ввод проверяется в браузере и на сервере. Обращения записываются в таблицу feedback.

| URL | Назначение |
| --- | --- |
| /, /cards | Каталог |
| /cards/detail/{id} | Карточка |
| /feedback | Обратная связь |
| /auth/login, /admin | Вход и управление картами |
| /api/cards, /api/cards/detail/{id} | Данные каталога и карточки |
| /health | Проверка приложения и PostgreSQL |

В PostgreSQL шесть таблиц: cards, inks, card_sets, rarities, users и feedback. Карточка связана с набором, редкостью и одним или двумя цветами чернил. Пароли хешируются, админские операции требуют сессию и CSRF-токен.

Каталог загружается из SQL; Node.js не нужен. Доступные локальные изображения лежат в Lorcana/public/assets/cards, остальные загружаются по исходному адресу.

## Тесты

~~~powershell
dotnet test Lorcana.sln --filter "Category!=Postgres"
# Для PostgreSQL-тестов задайте LORCANA_TEST_DB с подключением к отдельной тестовой БД.
# Пользователю тестовой БД нужно право CREATE SCHEMA.
dotnet test Lorcana.sln --filter "Category=Postgres"
~~~

Тесты проверяют маршрутизацию, отдачу статики, обработку ошибок, экранирование и вложенность шаблонов, CRUD через ORM и работу админки с настоящей БД. Интеграционные тесты создают отдельную временную схему с маленьким набором данных.

Полный прогон без локальной установки SDK и PostgreSQL (нужен запущенный Docker Desktop):

~~~powershell
./tools/Test-Lorcana.ps1
~~~

Скрипт копирует исходники без .env и изображений в .local, запускает .NET 8 и отдельную временную PostgreSQL без публикации порта, выполняет все тесты и очищает только свои контейнеры. Рабочая БД не используется. TRX-отчёты остаются в .local/test-results-*. Первый запуск требует интернета для образов и NuGet.
